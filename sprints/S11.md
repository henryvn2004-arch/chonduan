# Sprint S11 — Review System

**Status**: ⬜ todo
**Workplan tasks**: P3-T01, P3-T02, P3-T03
**Estimate**: 18h
**Depends on**: Phase 2 core done (bidding, wallet, leads live)

## Scope
- `ReviewForm.tsx` modal trên project hub — auth required, rate limit 1 review/project/user
- Fields: overall rating (1-5 sao), pros text, cons text, `is_verified_resident` toggle, transaction_type (mua/thuê)
- `/api/reviews` POST — insert `project_reviews`, check duplicate, enforce 1/user/project
- Hourly cron `/api/cron/aggregate-reviews` — recalc `projects.review_avg_rating`, `review_count`
- `ReviewSection.tsx` hiển thị aggregate + list 10 reviews mới nhất, filter by transaction_type
- `AI pros/cons summary`: Claude Haiku batch summarize texts → update `review_pros_summary` / `review_cons_summary` weekly (Vercel cron)

## Out of scope
- Photo upload trong review
- Upvote/downvote review
- Q&A board (S13)
