# Sprint S14 — CĐT B2B (Developer Dashboard + Sponsored Hub)

**Status**: ⬜ todo
**Workplan tasks**: P3-T05, P3-T06
**Estimate**: 28h
**Depends on**: Phase 2 live, ít nhất 1 CĐT deal đã ký (Henry outreach P3-T07)

## Scope

### Phần 1 — Developer Dashboard (16h)
- `/dang-ky/cdt` — CĐT signup form (company name, tax code, contact, projects list)
- Admin approval gate: `/dashboard/admin/cdt` queue — approve / reject
- `/dashboard/cdt/` — main dashboard sau khi approved:
  - Danh sách projects được sponsor (link by slug)
  - Upload/edit: banner hero, logo, tagline, announcement text
  - Post announcement (sticky notice trên project hub)
  - Xem stats: page views, lead clicks, contact button clicks (từ `project_events` table)
  - Billing: hiện subscription tier + ngày gia hạn
- Auth gate: `user_type = 'cdt'` trong `user_profiles`

### Phần 2 — Sponsored Project Hub (12h)
- Khi project có `is_sponsored = true` + CĐT đã approved:
  - Hero banner section đầu trang (full-width, branded)
  - "Sponsored" disclosure label nhỏ
  - CĐT logo + tagline trong `DeveloperSection`
  - Announcement sticky bar (nếu có text)
  - CTA button riêng "Liên hệ CĐT trực tiếp" → phone/email của CĐT
- Project card trên map/search hiện badge "Chính chủ CĐT"
- Sponsored projects không ảnh hưởng ranking tự nhiên (chỉ thêm UI layer)

## Out of scope
- Self-serve payment cho CĐT (deal B2B, invoice thủ công giai đoạn đầu)
- Analytics dashboard nâng cao (heatmap, funnel)
- Multiple CĐT per project
