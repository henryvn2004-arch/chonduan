## Scope

### P3-T14: Smart Search Natural Language (12h) — làm trước vì unblock search UX
- Claude Sonnet parse câu hỏi tự nhiên → structured filter params
- Input: "căn 2PN view hồ tầng cao Vinhomes dưới 5 tỷ" → `{project_name_hint: "Vinhomes", bedrooms: 2, price_max: 5000000000, floor_preference: "high"}`
- Fallback về keyword search nếu parse fail
- `/api/search/parse` endpoint riêng (gọi Claude → trả filter JSON → client gọi `/api/search` như bình thường)
- Cache parse results 1h (same query string → same filter)
- SearchBox.tsx thêm "AI search" mode toggle

### P3-T11: So sánh 2 dự án side-by-side (12h)
- `/so-sanh?p1=[slug1]&p2=[slug2]` route
- Load cả 2 projects SSR, render side-by-side table:
  - Giá/m², giá thuê, pháp lý score, amenities, risk indicators, phong thủy score, review rating
- AI-generated comparison verdict (Claude Haiku): "Dự án A phù hợp cho X vì..., Dự án B phù hợp cho Y..."
- "So sánh" button trên project hub (add to compare, max 2)
- URL shareable

### P3-T12: Buyer Persona Match (12h)
- `/goi-y` page — wizard 4 bước chọn persona:
  - Mục đích: ở thực / đầu tư cho thuê / chính sách expat
  - Budget range
  - Ưu tiên: trường học / yên tĩnh / giao thông / phong thủy / view
  - Khu vực prefer (optional)
- Claude Sonnet map persona → weighted filter → semantic search top 10
- Kết quả: project cards ranked với explanation ngắn tại sao match
- Không cần login

### P3-T13: News Digest Weekly Email (12h)
- Vercel cron mỗi thứ 7 lúc 8:00
- Claude Haiku: tổng hợp top 5 tin tức bất động sản tuần từ `khao_luan` + external RSS feeds (CafeF, BDS, Nhịp cầu đầu tư)
- Phân theo region: HCM / HN / Đà Nẵng / Toàn quốc
- Email template (`/api/cron/weekly-digest`) → gửi qua Resend/Sendgrid
- User subscribe: checkbox trong profile settings + `/api/newsletter/subscribe`
- Unsubscribe link trong email (1-click, no login required)
