# Sprint S13 — Community Q&A Board

**Status**: ⬜ todo
**Workplan tasks**: P3-T04
**Estimate**: 10h
**Depends on**: S11 done (review system, auth pattern tương tự)

## Scope
- `QASection.tsx` trên project hub — hiển thị danh sách Q&A, form hỏi mới
- Auth required để hỏi; trả lời mở cho agent (verified) + user đã đăng ký
- `/api/qa` routes: POST question, POST answer, GET by project_id
- Vote helpful trên answer (1 vote/user/answer, toggle)
- Sort: unanswered first, sau đó by vote count
- Agent answers có badge "Môi giới verified" nếu `kyc_status = approved`
- Email notify: khi question mới (notify top-slot agents của project), khi có answer mới (notify người hỏi)
- Rate limit: 3 questions/user/day, 10 answers/user/day

## Out of scope
- Moderation queue (dùng flag button + admin review thủ công)
- Rich text / markdown trong answer
- Notify tất cả followers (Phase sau)
