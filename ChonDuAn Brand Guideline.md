# ChonDuAn Brand Guideline

## 1. Brand Overview

**Tên thương hiệu:** ChonDuAn  
**Tagline:** Chọn dự án tốt nhất  
**Sứ mệnh:** Giúp người dùng chọn đúng dự án bất động sản phù hợp nhất với nhu cầu của họ  
**Tầm nhìn:** Trở thành nền tảng decision engine #1 cho bất động sản tại Việt Nam  

**Brand Personality:**
- Tin cậy (Trustworthy)
- Thông minh (Intelligent)
- Hiện đại (Modern)
- Tối giản (Minimal)
- Hướng người dùng (User-first)

---

## 2. Brand Positioning

**Không phải:**
- Website đăng tin BĐS
- Chợ listing

**Là:**
> Nền tảng giúp người dùng *chọn đúng dự án + kết nối đúng môi giới*

---

## 3. Logo System

### 3.1 Primary Logo
- Icon: Tòa nhà chung cư (high-rise) + base shape (nền)
- Wordmark: `ChonDuAn`
- Style: Modern, geometric, tech-driven

### 3.2 Logo Variants
- Full logo (icon + text)
- Icon only (favicon / app icon)
- Monochrome (đen / trắng)

### 3.3 Clear Space
- Khoảng cách tối thiểu = chiều cao chữ "C"

### 3.4 Do & Don’t

**Do:**
- Giữ đúng tỷ lệ
- Dùng đúng màu brand

**Don’t:**
- Không kéo giãn
- Không đổi màu tuỳ tiện
- Không thêm shadow / effect lạ

## 5. Typography

### Primary Font
**Poppins**

### Font Weights
- Bold → Heading
- Medium → Subheading
- Regular → Body
- Light → Caption

### Usage

| Element     | Size | Weight |
|------------|-----|-------|
| H1         | 32–40px | Bold |
| H2         | 24–28px | Semi-bold |
| Body       | 14–16px | Regular |
| Caption    | 12px | Light |

## 7. UI Principles

### 7.1 Design Philosophy

> Ít nhưng chất — không overwhelm user

### 7.2 Core UX Rules

- Không hiển thị quá nhiều dự án
- Luôn có **ranking / score**
- Focus vào **decision**

### 7.3 Layout

- Map-first UI
- Split view:
  - Left: Filter
  - Center: Map
  - Right: List
